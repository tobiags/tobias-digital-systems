# Triage Labels

Canonical triage label vocabulary used across tickets:

- `needs-triage`: A new incoming task or request requiring assessment.
- `needs-info`: Blocked waiting on external assets, design clarification, or user inputs.
- `ready-for-agent`: Fully specified ticket ready for autonomous agent execution.
- `ready-for-human`: Requires manual human review, production deployment verification, or real credential access.
- `wontfix`: Out-of-scope or dropped items.
