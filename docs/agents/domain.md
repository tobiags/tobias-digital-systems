# Domain Documentation

## Domain Model Layout
- **Single-Context Repository**: All ubiquitous domain terminology lives in `GLOSSARY.md` at the repo root.
- **Architectural Decision Records (ADRs)**: All irreversible, trade-off-heavy decisions live in `docs/adr/`.

## Active Discipline
- Challenge ambiguous words against `GLOSSARY.md`.
- Never pollute `GLOSSARY.md` with implementation code snippets.
- Document hard-to-reverse architectural choices as ADRs with Context, Options considered, Decision, and Consequences.
