# Issue Tracker

Issues and tracer-bullet tickets for this repository are tracked locally as Markdown files under `docs/tickets/`.

## Convention
- Each ticket is a single markdown file named `TICKET-<number>-<slug>.md`.
- Statuses: `TODO`, `IN_PROGRESS`, `DONE`, `BLOCKED`.
- Dependencies are explicitly declared in the header frontmatter / metadata block (`blocked-by: [...]`).
